## Task
Build a web application that helps university and college students manage their academic activities and access important campus services from one platform.

Your application should provide student registration, dashboards, class timetables, assignment management, personal notes, campus announcements and profile management.

The objective is to develop functional software that solves a real-world problem.

PROJECT REQUIREMENTS

Build a platform called CampusConnect with the following features:

1. USER REGISTRATION

- Students must be able to create accounts.
- Collect name, email and password.
- Validate registration information.

2. LOGIN SYSTEM

- Allow registered students to log in.
- Provide secure authentication.
- Allow users to log out.

3. STUDENT DASHBOARD

- Display a welcome message.
- Show student information.
- Display upcoming classes and tasks.
- Show important announcements.

4. TIMETABLE MANAGEMENT

- Add class schedules.
- Edit existing schedules.
- Delete schedules.
- Display classes by day and time.

5. ASSIGNMENT MANAGER

- Create assignments and tasks.
- Set deadlines.
- Mark tasks as completed.
- Edit and delete tasks.

6. PERSONAL NOTES

- Create study notes.
- Edit and delete notes.
- Save notes for future reference.

7. CAMPUS ANNOUNCEMENTS

- Display important announcements.
- Show announcement dates.
- Provide an admin mechanism for publishing announcements.

8. PROFILE MANAGEMENT

- View student profile.
- Update personal information.
- Change account details.

9. RESPONSIVE DESIGN

- Support smartphones, tablets and computers.
- Provide simple and accessible navigation.
- Maintain a professional user interface.
